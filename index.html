Stage 1 · Vocabulary Builder

A token ⓘ is one unit of text. The vocabulary ⓘ is the list of unique tokens, each with a Token ID ⓘ. Text is lowercased and split into words and punctuation.

TIDTokenCountStatus

Token frequency ⓘ counts how often one token appears. Vocabulary size ⓘ counts how many different tokens exist. "the the the" → frequency of "the" = 3, vocabulary size = 1. Removing a token re-numbers later IDs.

Stage 2 · Tokenization Lab

Modern tokenizers (BPE, WordPiece) use subwords, so they rarely need [UNK]. An unknown word is not an error — it just isn't in this vocabulary.

Stage 3 · Embedding Visualizer

Uses the words from Stage 2. A vector ⓘ is a list of numbers; an embedding ⓘ is a vector that represents a word. Token IDs are not embeddings.

Hover a point to inspect it. Click points to pick words A and B. Scroll to zoom, drag to pan (2D) or rotate (3D).

About

NLP LAB runs entirely in your browser (no server, no paid API). Spelling embeddings are real character features (letter frequencies, hashed character bigrams, length). Meaning embeddings are not a trained language model: they use a small hand-made concept lexicon and are a simplified educational approximation. Both are projected to 2D or 3D with PCA, which can distort distances.
